### 实验探索

#### AMCO

##### 当前问题

当前单调层为：$y_j = \sum_k w^+_{jk}\phi(x_k) + \sum_k w^-_{jk}\phi(-x_k)+b_j, $

其中：$w^+_{jk}\ge 0,\qquad w^-_{jk}\le 0.$

记：$a=w^+_{jk},\qquad b=-w^-_{jk}\ge 0, $

则局部导数为：$\frac{\partial y_j}{\partial x_k} = a\phi'(x_k)+b\phi'(-x_k)\ge 0. $

使用 ReLU：$\frac{\partial y}{\partial x} = \begin{cases} a,&x>0,\\ b,&x<0. \end{cases}$

它不会产生普通 ReLU 网络意义上的死神经元，但梯度会在 $a$ 和 $b$ 两条路径之间突然切换。

也就是说，即使隐藏表示只发生很小变化，梯度路径也可能完全打开或关闭。

由于隐藏表示依赖：$x=x(\mathbf Q,z(s)), $

状态变化、个体 Q 值变化或者参数更新，都可能改变 $x$ 的符号。因此同一个 agent 在不同 transition 上可能得到完全不同的 credit 梯度。多层网络会放大这种差异，因此：

- 某些 transition 打开了较多高权重路径，梯度较大；

- 某些 transition 关闭了较多路径，梯度较小；

- 多层路径组合后，差异会进一步积累。

这就可能形成宽尾梯度分布。

这与 `5m_vs_6m` 的现象吻合：

- `credit_grad_cv` 后期约 0\.9；

- p10 下降到约 0\.2；

- p90 仍约 2\.5；

- grad norm 的 p95 约 13–15；

- TD error 和 loss 持续较高。

因此，ReLU 的主要问题不是零梯度，而可能是分段切换导致的高方差梯度。

##### 实验策略

替换当前激活函数为：Softplus：$\phi(x)=\log(1+e^x),\qquad \beta=1.$

导数为：$ \phi'(x)=\sigma(x), \qquad \phi'(-x)=1-\sigma(x). $

因此 AMCO 层的导数变成：$\frac{\partial y}{\partial x} = a\sigma(x)+b[1-\sigma(x)]. $

于是：$\min(a,b) \le \frac{\partial y}{\partial x} \le \max(a,b). $

这是 Softplus 最适合当前问题的地方：

- 像 ELU 一样平滑地连接两条权重路径；

- 不会像 ELU 那样在零点附近得到 $a+b$；

- 不会超过两条路径中较大的权重；

- 不产生饱和到零的硬梯度；

- Softplus 单调且非有界，仍符合 AMCO 使用非饱和单调激活的基本方向；

- 单调性和 IGM 认证保持不变。

##### 实验结果

1. **Softplus 明显改善了 ****`5m_vs_6m`****，其中 ****`beta=1.0`**** 是当前最适合进入多 seed 验证的配置；ELU 应直接淘汰。**

2. **Softplus 确实压低了 credit 梯度上尾，关键梯度统计：**

    这验证了之前的核心判断：ReLU 的问题主要不是梯度消失，而是双分支切换产生的梯度条件数和上尾问题。

3. **末期 ****`state_to_q_ratio`****：**

    ```Plain Text
    ReLU             1.04
    Softplus β=0.5   0.59
    Softplus β=1.0   0.47
    ELU              0.49
    ```

    Softplus 使第一层的 Q 分支相对更强，状态项相对减弱。这在 `5m_vs_6m` 上改善了性能，但还不能说明它适合所有地图。

    尤其需要警惕：

    - `3s5z` 需要状态条件化的异质 credit 分配；

    - `2c_vs_64zg` 之前后期 `state_to_q_ratio` 接近 1\.8；

    - 如果 Softplus 在这些地图上让状态项过弱，可能削弱 PMIX 想表达的状态—个体价值交互。

    所以必须做跨地图保护性实验。

##### 实验分析

**核心结论是：**

> Softplus β=1\.0 能改善同质地图上的 credit 条件数和学习速度，但会在 `3s5z` 上几乎关闭直接状态分支，导致严重的跨 seed 不稳定。因此现在还不能把它确定为 AMCO 的统一默认激活。
> 
> 

**状态分支几乎消失：**

最重要的证据是 `state_to_q_ratio`：

Softplus 将 `3s5z` 的直接状态项压低了约 98%。

而且不是训练后期才衰减：两个 seed 的 `state_term_rms` 从早期开始就只有约 `0.02`，之后几乎不增长；Q 项则逐渐增长到约 `0.75–0.84`。

因此当前 Softplus `3s5z` 实际接近：$Q_{\mathrm{tot}} \approx M(\mathbf Q)+V(s),$

而不是预期的：$Q_{\mathrm{tot}} = M(\mathbf Q,z(s))+V(s).$

其中 $V(s)$ 是 action\-independent 的，只能拟合状态基线，不能提供状态条件的 agent credit 调制。

**3\+5 分组仍然存在**

Softplus 下前 3 个和后 5 个 agent 的平均梯度仍有明显差异：

```Plain Text
seed141 max/min ≈ 1.75
seed41  max/min ≈ 2.13
```

所以失败不是“所有 agent credit 完全均匀”。更准确地说：

> AMCO 仍学到了静态的单位类型差异，但几乎失去了随状态变化的条件 credit 分配。
> 
> 

这解释了为什么 seed141 可以依靠幸运的策略轨迹取得高胜率，而 seed41 无法恢复：缺少状态条件调制后，学习结果更加依赖初始化和早期探索。

**当前判断**

Softplus β=1\.0 的能力边界已经比较清晰：

- 对同质 credit 结构：有效；

- 对低 agent 数、状态基线较强的任务：基本有效；

- 对需要状态条件异质 credit 的任务：可能产生状态分支学习饥饿和严重 seed 敏感性。

##### 改进方案

Centered Softplus 满足：$\phi_c(x)=\operatorname{Softplus}(x)-\log 2,\qquad \phi_c(0)=0,\qquad \phi_c'(x)=\sigma(x)>0.$

它与普通 Softplus 有完全相同的导数形式和单调性，但去除了每层在零点产生的正输出偏置。当前结果支持这样的解释：正偏置会改变多层 AMCO 的前向尺度和优化轨迹，使 Q 项占据输入层；中心化重新平衡了 Q 与状态项，同时保留平滑梯度。

不过，`state/Q ratio` 仍不能直接证明状态正在动态改变 credit。论文若要声称“state\-conditioned credit adaptation”，更直接的诊断应当是固定 Q、打乱状态后比较：

$D_{\mathrm{state}} = \mathbb{E} \left[ \frac{ \left\| \nabla_{\mathbf q}F(\mathbf q,\mathbf z) - \nabla_{\mathbf q}F(\mathbf q,\widetilde{\mathbf z}) \right\|_1 }{ \left\|\nabla_{\mathbf q}F(\mathbf q,\mathbf z)\right\|_1+\varepsilon } \right].$

##### 实验结果

MMM2与3s\_vs\_5z地图上效果提升明显，3s5z与2c\_vs\_64zg地图上效果下降，ReLU 会随着训练逐渐增强状态对 mixer 的影响；Centered 基本一直停留在低水平。这正好解释了曲线：它能够学会基础策略，却较难从中等胜率过渡到需要角色配合的高胜率。**Centered Softplus 抑制了极端梯度，但同时抑制了某些地图上有用的、状态相关的选择性 credit 放大。**

最新完整 run 中：

$\text{credit\_grad\_near\_zero\_frac}=0, \text{credit\_grad\_negative\_frac}=0, $

各层 centered\-softplus slope 也没有明显饱和。因此当前 AMCO 的主要问题不是“agent 完全收不到梯度”，而是：

- 不同地图需要不同程度的 credit differentiation；

- state/Q 交互强度具有地图依赖性；

- 相同激活曲率无法在所有地图同时最优；

- TD 学习存在 seed 敏感性。

beta=2 真正暴露的问题不是激活函数，而是部分 seed 没能建立足够的状态\-Q交互：**成功 seed 和失败 seed 的主要差异是状态分支有没有充分参与，而不是 credit 梯度消失，也不是 beta=2 饱和。**

#### HLL

##### 当前问题

HLL 当前最大的困难不是容量不足，而是个体 Q 到 lattice 坐标的表示不适定，以及层级顶点参数化带来的早期梯度偏置。

1. 个体 Q 到 lattice 坐标的表示不适定

    HLL 的最终梯度是：$\frac{\partial Q_{\mathrm{tot}}}{\partial Q_i} = A(z) \frac{\partial L}{\partial c_i} \frac{c_i(1-c_i)}{T}. $

    因此只要 sigmoid 部分饱和，整个 credit 梯度就会变小。

    这就是“表示不适定”的含义：

    - 函数本身是定义良好的；

    - 但 Q 的绝对平移和尺度没有稳定的语义；

    - 不同 seed 可能学出数值位置不同、策略却相近的 Q；

    - HLL 却会把这些数值差异当成不同的 lattice 区域。

    当前结果正好体现了这一点：

    - MMM2 的 T=1、seed141 主要陷入低端饱和；

    - `3s_vs_5z` 的 K=2、seed41 主要陷入高端饱和；

    - T=2 可以救回 MMM2 seed141，却让 MMM2 seed41 进入“没有硬饱和但整体梯度很弱”的状态。

    所以固定调大或调小 T 不是根本解决方案。它只能在“硬饱和”和“全局梯度变弱”之间移动。

2. 当前层级顶点参数化有固有的梯度偏置

    HLL 当前使用：$\theta_{\mathbf v} = \ell_{\mathbf v} + p_{\mathbf v}(z) \bigl(1-\ell_{\mathbf v}\bigr), $它有一个副作用：越到高层，剩余 headroom 越小。

    当前配置把所有辅助网络最终 bias 初始化为：$-2, \qquad p=\sigma(-2)\approx0.119. $

    所以低层增量较大，高层增量天然很小。这不是训练后才产生的现象，而是初始化结构本身造成的。

    在 K=6、K=16 的 lattice 中，最大层级较高，因此会出现：

    - low\-level vertex slope 较大；

    - mid\-level slope 下降；

    - high\-level slope 接近零。

    这就是所谓“早期梯度偏置”：高层顶点从一开始就比低层顶点更难获得有效更新。

3. 容量不足和优化困难不是一回事

    但训练是否成功还取决于：$A(z) \times \frac{\partial L}{\partial c_i} \times \frac{c_i(1-c_i)}{T}. $

    因此：

    - 顶点数量多，不代表梯度一定健康；

    - 顶点数量少，也不代表一定无法完成任务。

    实验已经说明：

    - K=6 的 `3s_vs_5z` 可以成功；

    - K=2 的 `3s_vs_5z` 某些 seed 也可以成功；

    - 但 K=2 的另一个 seed 会因为早期饱和而失败。

    这说明 K=2 不是“表达能力绝对不够”，而是优化轨迹更不稳定。

4. V、A 与 lattice 偏置的冗余

    当前 HLL 是：$Q_{\mathrm{tot}} = V(z)+A(z)\left[L(\mathbf c,z)-0.5\right]. $

    这里默认认为 lattice 输出 $L$ 大致位于 $0,1$，所以减去 $0.5$ 就相当于居中。

    但实际情况下，lattice 的顶点值不是固定的 0 和 1，而是状态网络根据 $z$ 生成的。例如某个状态下：

    $\theta_-(z)=0.2,\qquad \theta_+(z)=0.6. $

    那么整个 lattice 的输出范围是：$L(\mathbf c,z)\in[0.2,0.6]. $

    此时 lattice 的真正中心是：$ \frac{0.2+0.6}{2}=0.4,
$

    而不是 `0.5`。

##### 改进方案

把当前固定的：$c_i=\sigma(Q_i/T) $

替换为：$c_i=C_\psi(Q_i) = \sigma\left( \frac{Q_i-b}{\tau_{\min}+\operatorname{softplus}(\rho)} \right),$

其中：

- $b
$ 是可学习的全局平移；

- $\rho$ 控制正的尺度；

- 所有 agent 和所有 lattice 维度共享同一组 $b,\rho$；

- 不使用 map\-specific 的 $b或\tau$；

- 不让 $b,\tau$ 依赖状态。

这样做的优点是：

1. 可以自动适应 Q 的平移；

2. 可以自动适应 Q 的尺度；

3. 严格保持单调性；

4. 不依赖 batch 中其他 agent 的 Q；

5. 不增加状态条件参数生成；

6. 只有两个共享标量，参数开销可以忽略；

7. 不需要 AMCO、MonoKAN 也增加同样的无关模块。

##### 实验结果：

效果几乎没有任何提升
